# Duhodah Audio Files

Ovdje spremi MP3 datoteke za audio player na web stranici.

## Trenutne pjesme (dodaj MP3 s ovim imenima):
- 01-disanje-kao-domovina.mp3   → 'Disanje kao Domovina' (Ethereal Ambient, HR)
- 02-breath-as-homeland.mp3     → 'Breath as Homeland' (Ethereal Ambient, EN)
- 03-tiha-poplava.mp3           → 'Tiha Poplava' (Dark Dream Pop, HR)
- 04-the-silent-flood.mp3       → 'The Silent Flood' (Dark Dream Pop, EN)

## Dodavanje novih pjesama:
1. Spremi MP3 u ovaj folder
2. Otvori website/index.html
3. Pronadi TRACKS niz u <script> sekciji
4. Dodaj novi objekt:
   { title: 'Naziv', desc: 'Žanr · Jezik', file: 'audio/filename.mp3', dur: '8:00', art: '🎵' }
